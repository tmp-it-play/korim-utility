# KoRim Utility

현재 버전: **0.3.0**

한국인 플레이어를 위해 림월드의 부족한 부분을 채워가는 모드입니다.

한국어 번역 보완부터 편의 기능, 아이템과 UI까지 조금씩 추가합니다.

## 노예 억압 개선

Ideology와 Harmony가 활성화되어 있으면 기존 간수의 노예 억압 작업을 개선합니다.
사교 3, 억압력 20% 이상인 간수가 시도할 수 있으며, 억압력에는 전투 기술과 장비,
강화된 신체 능력, 지위와 정착지 재산도 반영됩니다. 상대 노예의 능력과 복종심에 따라 성공률이 달라집니다.

억압에 성공하면 노예에게 복종심에 따른 무드 페널티가 1일 동안 적용됩니다.
노예제를 명예롭게 여기는 이념은 페널티가 절반이며, 마조히스트는 대신 +5를 받습니다.
효과는 중첩되지 않고 갱신됩니다. 억압할 간수가 없으면 우측 경고 목록에 표시됩니다.

모드 설정에서 **복종심 상승 배율**과 **억압 난이도**를 따로 조절할 수 있습니다.
난이도는 최소 자격을 통과한 뒤의 성공 확률만 바꾸며, 무드 지속시간은 1일로 고정됩니다.
실패하면 복종심과 무드는 그대로이고 기존 하루 재시도 간격을 따릅니다.

자세한 계산과 판정 기준은 [설계 문서](docs/slave-suppression.md)를 참고하세요.

KoRim Utility
Korean translations by snowykte0426.
Original KoRim Utility code and translation contributions: MIT; see LICENSE.
Third-party material remains subject to the notices below.

This is one mod with optional translations. Each translation folder loads
only when its corresponding original mod is active. No translation target
is required to use KoRim Utility. No upstream gameplay definitions,
assemblies, textures, preview images or Workshop publication IDs are included.

Generated RJW medical item artwork
Visual references: RimWorld HealthItem by Ludeon Studios, and Bionic icons
by AUTOMATIC (https://steamcommunity.com/sharedfiles/filedetails/?id=1677616980).
Revision 2 reuses the existing game/mod case texture paths without redrawing
the cases. Organ masks were regenerated with the built-in image_gen tool,
using the original Heart, Lung, ReproductiveOrgans masks and preview as
references. Only generated masks are bundled, at unique KoRimUtility paths.
Bionic icons is optional; its case textures are referenced only when active.
Its MIT notice (Copyright (c) 2018 AUTOMATIC1111) is included in
ThirdPartyNotices/BionicIcons-LICENSE.txt. No upstream code or case textures
are bundled.

KoRimUtility.MedicalIcons.dll is original compatibility code under LICENSE.
It isolates RJW map texture instances to prevent atlas mask collisions and
composes UI textures at runtime from the active game/mod artwork. Existing
Bionic icons organ UI images retain their original masks. The upstream
textures and BionicIcons.dll are not modified or redistributed.

KoRimUtility.MainButtons.dll is original UI layout code under LICENSE.
It assigns equal widths to visible main menu buttons while retaining the
game and mod workers. It loads only when the Harmony mod is active.
Harmony and RimWorld assemblies are build dependencies and are not bundled.

# 정착지 관리 기능

RimWorld 1.6의 기존 간수 작업 `SuppressSlave`와 복종심(`Need_Suppression`)을 확장한다.
Ideology와 Harmony가 모두 활성화된 경우에만 기능, 정의, 설정을 로드한다.
새로운 간수 작업이나 별도의 복종심 수치는 만들지 않는다.

## 합의한 동작

- 최소 사교·억압력 조건을 통과한 간수만 기존 억압 작업을 수행한다.
- 자격 조건은 고정한다. 자격을 갖춘 간수의 성공 확률은 상대 노예의 전투 능력과 현재 복종심에 따라 결정한다.
- 실패하면 복종심과 무드가 변하지 않으며 별도의 실패 메시지도 띄우지 않는다.
- 성공할 때 노예에게만 무드 효과를 준다. 작업 직전 복종심으로 단계를 결정한다.
- 모든 무드 효과는 1일(60,000틱) 동안 유지한다. 만료시간 설정은 제공하지 않는다.
- 다시 성공하면 같은 기억의 단계와 나이를 갱신한다. 더 약한 페널티로 교체될 수 있다. 중첩하지 않는다.
- 실패와 취소는 기존 기억의 만료시간을 갱신하지 않는다.
- 게임의 기존 하루 재시도 간격을 유지한다. 실패해도 즉시 반복 시도하지 않는다.

## 작업 자격과 억압력

초기 균형값은 사교 3 이상, 억압력 20% 이상이다. 간수 작업·말하기·조작이 가능해야 한다.
사망, 쓰러짐, 정신 이상 상태에서는 수행할 수 없다. 수동 우선 작업도 최소 조건을 우회하지 않는다.
장비나 상태가 작업 중 바뀌면 실제 억압 시점에 자격을 다시 확인한다.
실제 판정 시 노예의 처우도 다시 확인한다. 처우를 복종 이외로 바꾸면 억압력·성공률·무드 처리를 건너뛴다.

기존 `SuppressionPower`에 `StatPart_SuppressionAuthority`를 추가한다.
기존 사교, 의복과 다른 모드의 능력치 보정을 유지하며 추가 내역을 정보창에 표시한다.

| 추가 요소 | 최대 가산치 | 계산 기준 |
|---|---:|---|
| 전투 기술 | 12%p | 사격과 격투 중 높은 기술 / 20, 신체 상태 반영 |
| 공격 성능 | 12%p | 근접 DPS와 주무기 예상 원거리 DPS 중 큰 값 / 20 |
| 방어 성능 | 6%p | 신체 부위별 가장 높은 날카로움 방어 수치의 보호 범위 가중 평균 / 150% |
| 강화 신체 | 6%p | 조작·이동·시각 중 기본 100%를 넘는 능력의 합 / 150% |
| 지위 | 6%p | 작위 서열 / 600 × 6%p와 이념 역할 가산 중 큰 값. 백작부터 상한 적용 |
| 정착지 재산 | 3%p | 플레이어 거주지 재산의 로그 비례값 |

폭력 작업 불가 정착민은 전투 기술·공격 성능 가산을 받지 않는다.
이식물은 실제 공격과 신체 능력에 반영한다. 정착민·이식물의 판매 가격 자체에는 별도 가산하지 않는다.
방어구 가격이나 의복 개수 대신 보호 성능을 계산한다. 지위는 여러 작위와 역할을 합산하지 않는다.
부상으로 의식·조작·이동이 낮으면 전투 관련 가산도 낮아진다.

## 성공 확률과 상승량

기본 성공 확률:

`저항도 = 0.12 + 노예의 전투·공격·방어·강화신체 가산 합 + 0.15 × (1 - 작업 전 복종심)`

`성공 확률 = 1 / (1 + (저항도 × 난이도 / 간수 억압력)²)`

확률 범위는 5~95%다. 최소 자격을 갖추지 못하면 확률은 0%다.
노예의 저항도에 간수용 사교, 작위, 정착지 재산 보너스는 포함하지 않는다.
미리보기, 작업 검색과 경고 계산에서는 무작위 판정을 하지 않는다.

성공 시 기존 회복 곡선(복종심 0%에서 2배, 50%에서 1배, 100%에서 0.5배)에
간수 억압력과 복종심 상승 배율을 곱한다. 결과는 복종심 100%를 넘지 않는다.
기존 70% 미만 작업 조건, 노예별 하루 간격, 접근과 예약 조건을 유지한다.
직접적인 근접 공격으로 인한 기존 억압 처리는 이 기능의 성공 판정과 무드 처리 대상이 아니다.

## 무드

| 작업 직전 복종심 | 일반 | 노예제: 명예로움 | 마조히스트 |
|---|---:|---:|---:|
| 30% 이상 | -5 | -2.5 | +5 |
| 15% 이상, 30% 미만 | -10 | -5 | +5 |
| 15% 미만 | -15 | -7.5 | +5 |

마조히스트 판정이 이념보다 우선한다. 감경에는 노예 자신의 이념을 사용한다.
노예제를 단지 허용하는 이념에는 감경하지 않는다. 별도의 가학성 면제는 없다.
정의 하나의 7개 단계로 일반·감경·버프를 표현한다. 기본 무드 감소량 3종은 서로 중첩하지 않는다.
효과는 점진적으로 줄어들지 않고 1일 뒤 게임의 기억 갱신 주기에 맞춰 만료된다.
기억 단계와 경과 시간은 게임의 기본 저장 기능을 사용한다.

## 설정

KoRim Utility 모드 설정에는 두 슬라이더만 제공한다. 기본값 복원 버튼을 둔다.

- 복종심 상승 배율: 0.25~3배, 기본 1배. 성공한 작업의 상승량만 변경한다.
- 억압 난이도: 0.25~2.5배, 기본 1배. 낮출수록 성공하기 쉽다. 최소 문턱과 상승량에는 영향을 주지 않는다.

## 경고

기존 우측 경고 목록에 `노예 억압에 어려움`을 표시한다.
복종심 70% 미만이며 억압 모드로 지정된 노예가 있는데 같은 지도에 적격 간수가 배정되어 있지 않으면 표시한다.
다른 지도에 있는 간수는 담당자로 계산하지 않는다. 경고를 누르면 해당 노예를 확인할 수 있다.
설명에는 사교·억압력 기준과 작업 배정, 장비, 건강 상태를 확인하라는 안내를 제공한다.
수면, 현재 작업, 예약, 정상 재시도 대기시간은 경고 여부에 영향을 주지 않는다.
먼저 지도에 억압 대상이 있는지 확인한다. 대상이 없으면 간수 자격과 억압력을 계산하지 않는다.
간수 작업이 배정되지 않은 정착민도 억압력 계산을 건너뛴다.

## 검증 범위

- 실제 Harmony를 사용하는 자동 검사: 자동/수동 작업 자격, 실행 시 재확인, 조용한 실패,
  작업 전 복종심 사용, 무드 대상·갱신, 지도별 경고, 설정에 따른 계산 경계.
- 실제 게임 참조와 빌드하고 XML·한국어 키·패키지 구성을 확인한다.
- 별도 테스트 프로필에서 실제 게임의 능력치, 기억, 정의·번역 로드, 저장·불러오기를 점검한다.
- 다른 전투 모드가 자체적으로 추가한 투사체·공격의 모든 특수 효과까지 모사하는 전투 시뮬레이터는 아니다.
  장기적인 반란 빈도와 체감 난이도는 실제 플레이로 조정할 수 있다.
